## 5. الگوهای UX (Tablet)
- همه دکمه‌ها ≥ 56px؛ فاصله‌گذاری ضد لمس اشتباه.
- «Call» و «Complete» با تأیید (بدون تأیید برای «Call» — عمل سریع).
- حالت افقی برای صفحه ویزیت؛ عمودی برای صف.
- Offline: نوشتن دست‌خط همیشه ممکن (Local)؛ Sync بعداً.
- خطای `CLINIC_CONFLICT` (دو تب): Message + «نسخه من/سرور» (ADR-0014).
