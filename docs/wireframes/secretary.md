├──────────────┬──────────────┬──────────────┬──────────────┬──────────────────┤
│  🕐 نوبت‌های  │  🚪 حاضرین   │  ⏳ منتظر صف  │  📣 فراخوان   │  👨‍⚕️ در اتاق    │
│  امروز (18)  │  (6)         │  (4)         │  (1)         │  ویزیت (1)       │

## 5. الگوهای مشترک
- **Toast/Alert Real-Time:** «📣 دکتر: علی رضانی فراخوان شد — اتاق ۱» + صوت (Setting) — بالای صفحه.
- **خطای Transition:** Toast قرمز با `CLINIC_INVALID_TRANSITION` + وضعیت فعلی (دوبار کلیک روی «Checkout» → خطا).
- **لغوشدن/جابه‌جایی نوبت:** Modal با دلیل (الزامی برای Staff) + تأیید.
- **جستجو:** Debounce 300ms؛ نتایج با MRN + وضعیت نوبت امروز؛ کلید میان‌بر `/` برای فوکوس.
- **Keyboard:** `↑/↓` انتخاب ردیف، `Enter` Drawer، `C` Check-in، `F` فاکتور، `X` Checkout.
