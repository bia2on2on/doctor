### 3.3 Patient-record editing decision — owner relay record; author claims labelled as such

**Provenance.** The normative decision was relayed by the owner in chat (first relayed 2026-11-07; re-stated by the owner in the 2026-11-08 instructions of this task). PR #331 (`24ffd01e…`) is the *author's implementation* of that decision. This ledger records the decision itself from the relay — not from the PR body, not from the code — and records the PR body's own description of the implementation as **author claims**, separately.

**The owner-relayed decision (record, agreed semantics):**

- An **explicitly submitted empty** name, an **explicitly submitted JSON `null`** name, and a **whitespace-only or invisible-only** name (including bidi-control-only sequences) are **rejected clearly** with a validation error.
- If a name field is **omitted** from the request, the previously stored value is kept unchanged.
